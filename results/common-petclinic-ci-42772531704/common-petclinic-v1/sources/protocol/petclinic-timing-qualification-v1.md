# PetClinic timing runtime qualification v1

This is a single bounded qualification of the prepared v4 runner and independent timing loader. Selection is fixed to six previously exposed pairs: `owner_telephone_10`, `owner_omit_firstName`, `pet_valid`, `pet_omit_name`, `visit_valid` and `visit_omit_date`. The original owner-required, pets and visits batch contracts supply exact jobs, case identities, source hashes and branch order. Unique qualification slot IDs distinguish repeated batch-local job IDs. No repeat, resume, replacement or unexecuted boundary is dispatched.

Three valid controls must be clean and three rejected-prefix controls must show matched rejection. Any unexpected terminal stops the sweep. Transport, source, timing or cleanup failures retain the partial artifact and executor-error ledger; they cannot be certified as a successful semantic sweep. A terminal halt may pass independent reconstruction but remains halted. Each pair has a 120-second worker deadline. Six pair allowances plus 150 seconds for common frontend work fit within the 900-second outer watchdog. The workflow has a 16-minute execution step and 35-minute job deadline, and shares the manual-application concurrency group.

The source-qualified loader reuses the existing capture, reset, binding and semantic checks, and independently reconstructs the Node timing sidecars in Python. It requires raw-byte hashes, candidate/channel identity, exact sidecar inventory, finite monotonic endpoints, exact interval arithmetic, backend and branch-context cleanup, non-overlapping ordered intervals and a complete recorded total within the pair deadline. The summary must agree with the sidecars. Old wall-clock records are not converted or backfilled. Synthetic cross-language tests compare Node-written records with the Python verifier, including incomplete cleanup.

Frontend setup and teardown are separate common monotonic records. Browser startup remains separate per-pair common setup. The branch interval is the source-frozen v4 measure: before independent reset/startup through capture drain, context/backend cleanup, raw JSON write/readback and identity/hash validation; final sidecar and summary serialization are excluded. Parent semantic reconstruction occurs afterward and is not silently included in the branch measure. Failed semantic observations can have measured attempted work; unconfirmed cleanup or a missing end cannot have a complete branch cost. No cross-application speed ranking is supported.

The independent campaign verifier reconstructs every attempted slot, checks runtime source copies and environment records, and replays the stop decisions without trusting stored observations. All evidence is retained on success or failure. Qualification covers these observed paths only. P4 also needs the selected primary paths and preflight to enforce the timing contract; primary campaign bindings, batching, calibration and freeze remain open.
