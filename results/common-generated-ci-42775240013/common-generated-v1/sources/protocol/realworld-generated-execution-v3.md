# Generated mutation runtime execution v3

The runtime integrates the unchanged v3 preparation plan: one API-producer reference followed by seven retained generated mutation pairs, with independently reset API/UI branches. Selection, order, source-case hashes, policies and terminal decisions are not revised after execution. No repeats or resumes are dispatched.

The proven v2 worker, adapter, source-qualified reset records, cleanup checks and branch timing are reused. A versioned v3 runner passes transport-complete but semantically incomplete evidence to the v3 terminal bridge. The driver checkpoints started and completed jobs and stops at the first registered halt, including a halt on the last job. Reference failure stops the sweep. Worker failures, invalid reset/cleanup or unreadable artifacts remain retained executor failures and cannot pass the semantic-halt verifier.

Each worker has an 80-second deadline; recorded branch intervals must be at most 95 seconds. The outer watchdog is 1800 seconds with TERM then KILL after 20 seconds; CI step and job limits are 32 and 45 minutes. Common setup and frontend teardown are separate from measured branch cost. The planned eight pairs have at most sixteen branch slots.

Independent reconstruction rechecks archived source bytes, exact jobs, fixture/reset bytes, raw hashes, cleanup and timing. It recomputes every pair and replays the driver against the retained campaign ledger. Extra attempts after a halt, omitted observations, changed decisions, partial executor failure and primary promotion are rejected. Artifacts are retained on success or failure. A registered semantic halt returns a nonzero execution step but can pass independent verification; it does not become a completed campaign.

This remains exposed engineering qualification, not primary evaluation or independent defect adjudication. Unknown title requirements stay unknown. No database-write atomicity conclusion is inferred from HTTP status alone. Prior v2 control qualification and synthetic v3 preparation remain unchanged.
