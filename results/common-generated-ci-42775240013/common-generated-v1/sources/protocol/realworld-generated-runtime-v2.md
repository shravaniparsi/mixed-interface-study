# Generated exposed runtime qualification v2

Selection is exactly the two previously exposed route-only reference pairs: UI producer with API/UI continuations and API producer with API/UI continuations. Four independently reset branches run once in their frozen job order. There are no mutations, repeats, resumed attempts or primary samples. Every reference must classify clean before the next pair runs; an exception stops the attempt and its files remain.

The versioned worker retains the copied SQLite reset before backend startup. The unchanged generated adapter records browser ownership before launch. The worker stops Node and backend and performs marker/identity-based browser cleanup; the parent then confirms worker exit, performs another browser cleanup and verifies that the backend port closed. Frontend cleanup belongs to common setup/teardown and is recorded separately. Frozen older workers and loaders are unchanged.

The branch timer starts before worker launch and ends after reset, adapter execution, raw extraction, reset/cleanup validation and owned teardown, before the timing report is serialized. Common migration, fixture creation and frontend startup are outside branch timing. Workers have an 80-second external deadline; valid recorded branch totals must not exceed 95 seconds. A 600-second outer watchdog covers setup, all four branches and parent-side validation, with TERM followed by KILL after 20 seconds. CI step and job limits provide a final bound. Timeout or interruption cannot qualify a clean result.

The independent runtime loader checks exact job/case identities, source hashes, retained reset bytes, raw hashes, cleanup reports, timing arithmetic and component evidence. The pair bridge retains exact producer-state and reference equality; no update/comment normalization is imported. The validator reconstructs both pairs from raw files and rejects extra jobs/branches. Bootstrap records and pinned application revisions are retained. Source certificates establish byte provenance, not independent proof of scientific defect claims.

Qualification remains an exposed engineering check. It does not cover mutation-specific behavior, forced live browser interruption, selector calibration, general production databases or primary-study readiness. Failed attempts are retained separately and never repaired by substituting later branch evidence.
