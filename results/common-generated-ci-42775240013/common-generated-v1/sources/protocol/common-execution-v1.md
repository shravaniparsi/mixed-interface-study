# Fresh execution through common bindings v1

The first live bridge qualification selects two previously exposed PetClinic owner pairs: the valid telephone control and omitted first name. The common preflight checks this exact selection and its qualified branch order. Each pair runs once, with a 120-second pair limit and a 450-second outer limit, including frontend setup. Unexpected terminals stop the qualification. No automatic repeats, resumption, primary samples or untouched cases are authorized by this workflow.

The common executor creates an exclusive attempt directory before calling the adapter. It records a fresh random attempt identity, hosted run identity, exact outer-to-inner binding and start checkpoint. The PetClinic adapter invokes the unchanged v4 runner in an owned subprocess, retains cleanup evidence and reloads raw results through the existing independent timing and semantic loader. Existing directories cannot be overwritten. Failures retain a start checkpoint, available runtime files and an incomplete failure record.

A completed receipt hashes the complete runtime file inventory and reconstructed observation. The common terminal preserves the original terminal kind, outcome fields and semantic signature while replacing only the job identity with the outer campaign job. Both the original terminal and its mapping remain retained. This allows the same registered source template to serve a freshly executed repeat without relabelling historical observations. The general bridge accepts a follow-up only when the registered initial sequence authorizes that exact job; live follow-up execution is outside this two-control qualification.

The independent validator reloads raw application evidence, reconstructs the receipt mapping and campaign ledger, verifies source and environment hashes, and checks distinct attempt identifiers and backend process IDs. File hashes establish integrity, not proof against a malicious evidence producer. Freshness is supported by the source-qualified executor, exclusive directories, dispatch and cleanup records, run identity and raw application evidence. Retained files alone cannot cryptographically prove an application was executed.

Branch costs retain the v4 scope. Common bridge bookkeeping and frontend setup remain outside those costs; outer attempt clocks are provenance and are not pooled with branch costs. This qualification establishes only the PetClinic adapter and two exposed initial paths. Generated RealWorld adapters, other cases, live repeat paths, primary batching, calibration and freeze remain open.
