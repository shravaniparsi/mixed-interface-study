# RealWorld terminal dispatch v2: baseline qualification

The executable selection is exactly article-valid, comment-body-valid, profile-bio-valid and article-update-unique-partial from realworld-paired-controls-v1. Each supplies one API-produced baseline pair for its workflow. Initial consumer order alternates API/UI and UI/API. The common v2 planner writes immutable job intent before launching a pair. Only exact initial jobs and the planner's repetition-two/three candidate and same-workflow reference jobs are admitted. Boundary records and other engineering variations are not selectable.

Each job creates a fresh fixture and frontend process. Each branch copies the same offline SQLite fixture, starts a backend, runs the unchanged prospective adapter with its assigned consumer, and stops the backend. Generated runtime resources are confined to that job. Raw adapter records, branch timing, commands, registry, source copies, fixture references and worker exits are retained. Completed check mismatches are retained without rewriting raw checks. The versioned job runner does not modify any historical runner or adapter.

The outer launcher uses the existing owned-process scope helper with a new process session, a 180-second job deadline, five-second termination grace and two-second kill confirmation. A timeout, interruption, nonzero runner exit or missing job artifacts stops the campaign as an executor error, retaining the attempt; it is not inferred to be an application defect. Direct-child cleanup alone does not establish detached-descendant absence. Ordinary successful extraction additionally requires recorded frontend and backend exits and the adapter's capture/closure evidence. Broader new-launcher lifecycle fault injection is not qualified by the ordinary run.

For complete pairs the extractor checks actor, pre-state, prefix command/status, reset hash, distinct branches, accepted prefix state and intended consumer command. The established component reducer checks traces and input bindings. Missing evidence halts; incomparable complete branch observations remain incomplete pairs and are repeat eligible. Shared readback mismatches never become exclusive consumer signals. Stable signatures retain check identity, verdict, scope and comparability; raw identities and timestamps remain in evidence and binding checks but are not compared across freshly initialized jobs.

The common terminal policy controls repeats. A flagged initial baseline remains in its own reference-control history; later clean controls cannot erase a failed initial control. Synthetic tests exercise follow-ups and halt behavior. Ordinary live qualification expects four clean pairs/eight branches and zero follow-ups. It does not claim live negative-path qualification or new independent samples.

The independent validator replays the recorded schedule through extraction, checks source copies against the executing source version, reconstructs terminal envelopes and the full ledger, and rejects extra job directories. All attempts are retained; no resume or replacement is permitted within an attempt. The entry point is an engineering qualification suite, not a primary evaluation. P2 and the primary freeze remain open.
