# Quartz terminal integration v2

This versioned integration qualifies the terminal contract on the four registered ordinary controls (two pairs) and synthetic negative evidence. The 40 unexecuted mutation branches remain excluded. The pinned application, adapter, registry, cleanup functions and 75-second branch deadline are unchanged. Version 1 runners and archives retain their original interpretation.

The v2 pair runner preserves the raw adapter status for a confirmed exit of 0 or 1. After the existing teardown completes, it invokes `quartz_terminal_outcomes.py` with a 10-second bound to classify the branch from its recorded result, run and pinned registry. Only a `continue` decision permits the second fresh branch. A classifier exception halts. The final extractor calls the same classification function and verifies archived source, registry, order and run-record identity. A nonzero pair-runner exit is not automatically discarded; an outer timeout, hard kill or unconfirmed exit still prevents further dispatch.

The adapter deliberately returns exit 1 for incomplete execution and for completed non-pass route controls. The classifier verifies the exact expected exit before presenting a copy with a zero transport exit to the unchanged component reducer. Original files and actual exit metadata remain retained. This adaptation does not manufacture completion, missing checks, prefix state or channel verdicts.

Application response failures require the pinned adapter's `application_read_response` error, an exact matching final direct-API GET trace (phase, registered path, HTTP status and message), successful authentication, actor evidence, registered producer request, a verified initial empty state and required observations preceding the failure. Authentication/reset errors, unsupported traces, source mismatches, malformed evidence, timeouts and failed cleanup do not qualify. Partial observations remain incomplete, receive no exclusive channel credit and cannot become stable defect findings. Completed check mismatches, matched rejection and unresolved policy retain their distinct meanings.

Runner cleanup and browser/JVM ownership logic are unchanged. The new bounded classifier runs after teardown and cannot launch an application. Fixture tests exercise policy classes, invalid trace/provenance, exact intentional exits and fixed diagnostic repeats. Hosted qualification executes only ordinary controls, regenerates the full campaign ledger from raw evidence and checks source and environment identity. New primary routes still require P2 binding and P3 bounded batches; this integration is not a primary freeze.
