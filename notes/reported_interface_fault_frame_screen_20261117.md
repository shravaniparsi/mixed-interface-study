## Scientific decision

No case is admitted for execution. An issue body can motivate a hypothesis but cannot certify a defect or its cause. A later admission protocol must pin the original application and backend, recover the external input without inventing the missing behavior, identify independent fix evidence, preserve related cases as clusters, and define a matched API baseline. Supplying the null-field predicate only to the proposed method would invalidate the comparison. An API comparator given that same predicate may detect the problem directly; the report alone establishes no incremental value for a browser continuation.

This screen is not used to replace the fifteen-task benchmark denominator. It tests whether a separate retrospective sensitivity benchmark may be feasible. One reported candidate is insufficient for Q1 readiness or a broad method claim. The collector and integrity verifier preserve the fixed frame and zero admissions. Full bodies and author profiles are not published; original response bytes are retained locally outside the repository and hashes bind the public metadata to that snapshot. Published labels remain auditable judgments rather than automatic ground truth.
