# Current transfer evaluator loses coverage to native replay

Under the fixed 5140925 protocol, all five prior API fixture bodies supplied login, email and password observations in fixed order. Both methods received the same explicit strings; neither filled absent password. The target was controlled isolated field validation. It was not full frontend-state reconstruction, which remains unresolved for all five bodies because confirmation and lifecycle context are missing and extra request fields are not emitted by the form.

The unchanged supplied-rule transfer evaluator produced 3 satisfied, 1 violated and 11 unknown field results. Native Angular 14 replay produced 11 satisfied, 3 violated and 1 unknown. The four jointly determinate results agree. Ten extra transfer abstentions arise from unsupported login-pattern/email predicates; both abstain on the absent password. No code errors occurred. These are 15 correlated field observations from five exposed fixtures in one application, not 15 independent trials.

The transfer translation and projection were analyst-defined. Original replay used the previously qualified source initializer, with its emitted hash checked. Native control.setValue evaluates one explicit field; it does not prove a form can be submitted or that an API request violates an intended obligation. Do not merge these verdicts into whole-request accuracy or report abstention as correctness. No backend rerun or model call was made.

This result fails to support a practical advantage for the current evaluator. The previous schema/backend differences do not establish a new-method contribution: native replay supplies broader field decisions than the candidate. Freeze this unfavorable result. Do not patch regex/email and rerun these same fixtures as independent evidence, and do not open reserved implementations merely to seek favorable examples.

Before a held-out comparison, the method needs a defensible distinction beyond recoding native validators: for example, a measured acquisition or portability benefit at matched semantic coverage, tested against a competent replay implementation with all costs counted. That is a research question, not an established advantage. Independent correctness evidence and the request-side logical baseline remain unresolved. The present package is useful development evidence, not a Q1-ready contribution.
