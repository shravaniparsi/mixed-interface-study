The current design requires the target and unrelated edit to be semantically independent, and fixes omission/null producer variants before outcomes. The original tag editor computes blank color from the current name. Therefore, under the very states this schedule is intended to probe, the proposed unrelated name edit can itself change the value used for the color target. Merely fixing an explicit ordinary color would not establish independence for the scheduled omitted/null target states.

Under that unchanged requirement, the mapped tag workflow is not source-qualified. Do not weaken the criterion to an ordinary-state-only check or restrict the schedule to obtain a qualification.
