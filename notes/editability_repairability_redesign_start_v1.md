# Approved redesign and refreshed exposure boundary

On 18 November 2026 the user selected redesign around editability and repairability.
The pending direction decision in research-feasibility-decision-v1 is historical
and is superseded by editability-repairability-design-v1 for that decision only.
The failed catalog study, zero qualified scientific cases and all stopping limits
remain unchanged. No old project was reopened and no new cohort was selected.

The design distinguishes native editability, prespecified repair effects and
unintended state changes. It retains source-aware replay as a competent comparison
channel and does not claim an algorithmic advance from response/schema failures.
It permits different native/API transport formats because it measures a different
question; it does not pretend the previous exact-request comparator now qualifies.

The reference exposure refresh scanned 12,503 tracked text blobs (190,597,859
bytes) at the pre-redesign HEAD. The index contains 1,567 repository references,
including all 347 previous references and every closed catalog project. It retains
19,116 non-blob/missing entries, 298 nontext-extension entries and two oversized
entries. No network fetch, app installation or application execution was required.

References are not equivalent to source inspection or outcome exposure. Catalog
metadata, dependency links and direct acquired application sources may all mention
a repository. Before sampling, classify those levels using actual provenance and
keep unresolved cases explicit. Do not describe all newly referenced projects as
runtime-tested, or treat absence of a reference as proof of no exposure. This
refresh covers tracked local objects, not all unavailable history, conversation,
untracked data or model-training exposure.

The design is not an executable registration. Population selection, exact revisions,
per-workflow obligation/state mapping, source-aware baseline coverage, input/repair
values and budgets must be instantiated prospectively. The next useful step is
that provenance classification and sampling-frame feasibility decision, not more
authored positive examples or application retries.
