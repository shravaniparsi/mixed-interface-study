# Quartz repeat-dispatch integration v1

The new pair-job runner accepts exactly two registered branches with identical producer operations, consumer intent, expectations and mutation metadata. Both continuation interfaces are required. Controls mode refuses mutations. The historical runner and adapter remain unchanged. A separate campaign entry point currently selects only the two ordinary control pairs; there is no primary-boundary option in that entry point.

The campaign archives sources, runtime sidecars, schedule, command and job intent before each launch. Every pair runs in a new evidence directory, and every branch starts a fresh RAM-store JVM. Completed branch records are reduced with the pinned historical component reducer. Pair checks compare actor, initial state, distinct JVM identities, observed prefix command/outcome, accepted business state and bound continuation intent. Missing or invalid evidence remains incomplete. Native payload mismatch is a comparability problem pending attribution, not automatic exclusive diagnostic credit.

The outcome bridge passes immediate, assigned and shared registered check failures to repeat selection. Only differing assigned-channel mismatch states set the channel-discrepancy flag. Unresolved-policy checks remain in observation signatures but do not independently trigger a requirement-failure claim. Failed shared checks can trigger repeats without being credited exclusively to API or UI. Signatures retain prefix and continuation responses, all component check verdicts, stored prefix and final job fields.

The driver records each job intent and outcome separately, stops on incomplete execution or unconfirmed cleanup, and never resumes or overwrites a prior attempt. It invokes the repeat planner only after a completed initial sweep. For flagged complete outcomes it dispatches both candidate repeats and accompanying reference controls. A subprocess failure halts the campaign with the attempted job retained. Source or output mismatches cannot become clean observations.

This qualification runs four ordinary branches. Healthy controls should produce no follow-up jobs. Synthetic executor tests exercise the flagged-repeat dispatch path; they are not application evidence. Negative-outcome fixtures test extraction categories but do not establish real boundary behavior. The forty Quartz mutation branches remain unexecuted pending the remaining primary-freeze gates. This step does not qualify interruption at every phase, cross-application timing, or detection effectiveness.
