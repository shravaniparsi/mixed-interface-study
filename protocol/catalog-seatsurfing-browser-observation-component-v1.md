# SeatSurfing browser observation and state capture

Prepare a browser-context observer for the later pinned runtime worker. Importing/testing this module starts no browser or application. Retain private request methods, URLs, bodies, headers, response statuses/headers and complete API fetch/XHR response bodies. Static-resource bodies are explicitly uncaptured; their build identities and request outcomes must be checked separately. Track response-evidence promises as well as pending requests so network completion cannot outrun evidence capture.

Bounds are 5,000 events, 16 MiB retained event data, 64 KiB request body and 512 KiB API response body. Body-size checks are observation limits after the browser receives data, not network-download or peak-allocation guarantees. The enclosing runtime must enforce process/resource/network limits. Unexpected origins, failed requests, oversized bodies or capture errors make quiescence unavailable. The observer itself does not route/block traffic; the worker must install the network boundary before navigation.

Require a 500-ms no-activity interval by default, with bounded observation waits and no retries or request replay. Expiration permanently invalidates this observer and preserves pending requests and never proves application-side failure or lack of side effects. This establishes observed browser-network quiet only; it cannot assert database idleness, actor identity or paused-container state.

State capture requires one application page/origin, no service/dedicated workers, empty sessionStorage and Cache Storage, and unchanged native access/refresh tokens with at least a two-minute remaining window. Capture original Playwright storageState including IndexedDB, wait for observation quiet, then require an unchanged second full snapshot and repeated session/cache/token diagnostics. Preserve original bytes and SHA256 for the coordinator. Do not clear unsupported state or insert replacement credentials. Unmapped state is a qualification condition requiring prospective support, not a natural incompatibility.

The returned record explicitly leaves actorVerified, applicationOperationsSettled and containersPaused false. The actual worker must establish those independently from retained runtime evidence before forming the joint checkpoint observation. Browser-memory equivalence is not claimed; the warm continuation still requires the same paused/resumed original editor, followed by separately verified restored branches.

Eleven synthetic tests use event-emitter and browser-state fakes, with no network or browser. They cover delayed body capture, pending requests, failures/external origins, response bounds, exact stable storage, changing storage, unmapped session state and token changes. No component result qualifies a scientific case before actual ordinary runtime comparison.
