Track source exposure, qualification failures and costs separately. A source quota is not a measurement of active human effort.

5. Per-system logical state scope and independent restoration qualification, including relevant stores/files/actor/browser/background activity. No after-outcome scope exceptions. Use synthetic infrastructure tests for any new persistence adapter before an application experiment.
6. Exact producer admission, ordinary gate, fixed sham/repair schedule, positive blocking evidence, unavailability, intended-effect frames and independent scoring. Retain all registered inputs, including safe rejections and already-editable states. No extra repairs chosen from errors.
7. Exposure/ancestry review against development, historical projects and the evaluation candidates before calling repository lineages independent. Source/provenance uncertainty must remain visible.
8. Project/workflow/field/input/pair denominators and a claim threshold based on actual evidence. No variant-level significance tests or global prevalence claims from this small bounded cohort. A second all-null result would be retained, not converted into algorithm superiority or Q1-readiness.
