# Complete runtime template map v1

All 75 retained entries are mapped without additions or exclusions: 73 pairs and two native-only controls, totaling 148 logical branches. Every template is validated by its existing registry-specific job validator. Case hashes use the original corpus canonical encoding, including literal Unicode. Runtime branch order is preserved. This map is preparation, not primary freeze or execution authorization.

References retain the same source case as the catalog control but use the candidate's runtime instrumentation and registry context. For example, identity candidates use the database-enabled identity runner for their reference, even though the single catalog baseline entry uses the expanded paired runner. These control executions are repeats of an existing control, not additional independent samples or new catalog entries.

The map carries the previous review's execution gaps and outcome limits. Mapping an exact template does not remove them. Primary dispatch still needs bounded immutable batches, runtime acceptance checks, explicit treatment of unsupported accepted states, fresh-attempt aggregation, cost validation, final smoke qualification and the dated freeze. Native-only controls remain outside paired comparison and repetition statistics.
