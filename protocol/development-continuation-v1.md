This is exposed development qualification on the original 21-points application, not independent evaluation. Checkpoint-v1/v2 failures, completed v3 restorations and the timestamp diagnostic remain closed. The diagnostic localized a repeat's seed/restored search difference to three timestamp precisions; it did not establish universal state equivalence. This control now measures actual edits rather than repeating read-only checks.

Seed starts a separate empty working directory, with original startup reindexing, and creates the identical ordinary input by API. Record the response and full readback. Any failed matching gate halts before that API update and is a qualification failure, not a native/API effect.
