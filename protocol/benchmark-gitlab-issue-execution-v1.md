Never retain credentials, tokens or cookies. The scientific branch count starts when production is attempted; setup failures are not accepted scientific inputs.

A fully observed triple passes only if all three paths succeed with equivalent setup, producer and final business states. Report producer rejection, instrument failure, producer-state mismatch, continuation-state mismatch and incomplete triple separately. An API rejection is not native-only evidence. Shared constraints receive credit in every path. No automatic natural-defect confirmation; requirement support and causal interpretation must be reviewed without adding outcome-selected cases.
