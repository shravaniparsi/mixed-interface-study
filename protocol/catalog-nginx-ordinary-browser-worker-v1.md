# Ordinary browser integration worker

The private JSON-lines worker connects native login/create/edit, exact API production/continuation, request observation and browser-storage capture/restore. It has not launched a browser or application. A complete qualification registration, isolated runtime and state gates remain prerequisites; no job is dispatched by this component.

Use one fresh worker per ordinary edit scenario under catalog-nginx-ordinary-checkpoint-amendment-v2.md. Pin Node 20.20.2, Playwright 1.62.1, Chromium version and executable SHA256. The origin is fixed to http://172.28.0.2:81 on the future internal Docker network. Production API requests execute through browser fetch with the original bearer token, same client address and browser transport. Native requests still come from original UI controls. Only the frozen ordinary producer and two frozen edit values are accepted. No altered scientific case is supported by this worker.

Intercept and deny every browser request outside that origin. Preserve each attempt. The source-known www.gravatar.com/avatar/ image request is a recorded blocked cosmetic dependency; any other external request fails qualification. No third-party request is allowed to leave the browser. The application/container network still requires an independent internal-network boundary. This cosmetic disposition is fixed before runtime outcomes and does not permit bypassing missing controls or application/API failures.

Observe all browser request starts/finishes/failures, enforce a 5,000-event bound, and retain immutable per-command private evidence. Quiescence requires networkidle, an empty pending-request set, the unchanged original token and sufficient expiry, and a conservative four-minute interval since native login. The original refresh implementation is not changed, suppressed or mocked; a token change fails the comparison. Browser observations establish only the browser part of quiescence. Application-operation completion, empty certificate state and initial timer completion remain separate live caller obligations.

Capture browser storage once per worker. Restored branches create a fresh browser context from that same stored state and reopen the original page, without re-login or injected React/form state. A command failure terminates the worker's operation loop; repeated command IDs are rejected and no failed command is retried. All envelopes and event files remain private because they may contain bearer tokens, synthetic credentials and persisted state. A future parent workflow must explicitly select redacted public results.

Current validation is syntax and static source review only. No pinned browser, native request equality, response/readback, refresh behavior, storage restoration or timing gate has executed. This component does not implement full-state comparison or certify a scientific case.
