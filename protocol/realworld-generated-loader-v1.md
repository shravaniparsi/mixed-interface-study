# Generated evidence loader and terminal bridge v1

This version is an offline contract implementation. Its loader accepts explicitly labeled synthetic bundles only, until an owned runtime supervisor can supply source, reset, cleanup and timing evidence. It validates the exact immutable job, all eighteen possible case bindings, source bytes against the checked-in implementation, the complete bundle file inventory, raw hashes, per-branch reset bytes, route and case identities. Absolute paths, escaping symlinks, unknown files, changed sources and self-declared runtime qualification are rejected. A certificate hashes recorded bytes; it does not attest that an application executed them.

The branch classifier uses the generated component extractor and requires capture and execution-integrity evidence. Cleanup failure takes precedence over interruption, timeout, worker failure and missing semantic evidence. A rejected prefix needs readable after-state evidence; an HTTP error alone cannot establish unchanged state. Registered unknown requirements remain unresolved when no higher-priority mismatch is observed.

The pair bridge requires both independently identified branches and matching reset, pre-state, producer status and submitted producer command. For accepted prefixes it additionally compares the producer state, returned reference and submitted continuation command. Generated references remain literal in this first version: the separate retrospective update/comment normalization is not transferred to create/edit cases. Different references or missing actions therefore prevent a clean paired conclusion. Assigned-channel discrepancy is separate from failures found by shared readback.

Tests cover file tampering, resealed source/case/reset substitutions, path escape, missing integrity evidence, cleanup and timeout precedence, and terminal decisions on explicitly synthetic reduced components. The complete positive live path remains unqualified; the synthetic terminal matrix is not raw-trace validation. The existing six binding tests also remain applicable. No application runs, primary samples or readiness promotions are added.

The present synthetic-only loader must be separately versioned when admitting runtime evidence. Primary dispatch remains disabled.
