## Native editability and fixed repair

For the ordinary state, run sham and repair for all four targets. For each accepted altered state, run sham and repair for its prespecified target, regardless of whether it appears problematic. The repair is the literal ordinary target value through the original control; the unrelated edit is the first other sorted independent pointer's fixed replacement. No repair is chosen from an error message.

Before continuation open the original editor using the persisted vanity, or generated code when vanity is null. Confirm stable-ID record correspondence, same actor, logical state, loaded form and browser state. Failure to load or act on original controls remains explicit unavailable evidence with captured page/request errors, not a fabricated successful edit or proof of blocking. Freeze a per-producer full database/file/browser/form checkpoint and independently verify its backup. Sham and repair each restore that checkpoint; starting state, actor, loaded form and browser identity must match before action. Include ordinary warm/restored behavior as a prerequisite, not an assumption about all process heaps.

D applies the exact same native actions but intercepts/aborts mutation requests before delivery. Require positive blocked-by-client evidence, unchanged logical state, then dispose context and restore browser/form/actor/state before U. D predicts request production/serialization only. A missing request within ten seconds is observation_unavailable unless an independently captured positive blocking mechanism supports a stronger label; timing alone never proves browser blocking. Preserve native errors and missingness. No forced submit or bypass of disabled controls.

U executes the original native action once, preserving actual request/response and independent state. Retain D/U request agreement separately from backend outcome. Successful intended edit requires the exact unrelated value, repair value for repair branches, and the complete declared frame, allowing only target updatedAt as a valid nondecreasing timestamp. A non-2xx request with unchanged state is native_request_rejected. Wrong/collateral writes and 2xx without intended persistence remain distinct. Every accepted state receives the fixed branch schedule unless an explicit state/observation qualification gate fails; retain the reason and denominator.
