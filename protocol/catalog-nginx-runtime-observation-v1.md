# Private live runtime observation

The observer has not run inside an application. It provides evidence for the future bounded coordinator and is not an atomic checkpoint, complete state-equivalence predicate, or dispatch authorization. The separate database/filesystem checkpoint, original startup completion, actor and native-control gates remain mandatory.

Invoke inside the original application container with the registered non-root PUID/PGID. Identify the unique original /app node index.js process through the peer-state checker, verify all real/effective/saved/filesystem UID/GID values and retain its kernel start ticks, executable SHA256, argv and working directory. Read the nginx master PID from its original PID file; require the actual executable to resolve to /usr/sbin/nginx, its original master-process title, and the same registered ownership. Recheck both process identities and the peer configuration after collection. This checks process continuity across this observation only, not continuity across intentionally restarted branches.

Require the actual backend environment to contain the full frozen build commit, production NODE_ENV, UTC TZ, IP_RANGES_FETCH_ENABLED=false, DISABLE_IPV6=true and registered PUID/PGID. Require CI, DISABLE_RATE_LIMIT and DEVELOPMENT absent. Return only these selected non-secret settings; do not dump the full environment or initial administrator credentials. The peer-secret predicate continues to verify exact original-template substitution and backend/proxy agreement separately.

Verify exact original hashes of nginx.conf and the HTTP/stream logging includes. Inventory /data, /etc/letsencrypt, /etc/nginx, /tmp/nginx, /var/lib/nginx/cache, /var/cache/nginx, /var/log/nginx, /run/nginx and /var/lib/logrotate. Retain paths, kinds, modes, UID/GID, nanosecond modification times, literal symlink targets, regular-file byte counts and SHA256. Do not follow symlinks. Reject noncanonical roots, unsupported file kinds, hard links or file metadata changes during hashing. Limits are 40,000 entries and 1 GiB of regular-file content per observation.

Use native Python os.listxattr, without following symlinks, to require no unrecorded extended attributes on these paths. This relies on Python availability in the original certbot image; absence or inspection failure makes the observation unavailable, with no package-install fallback in this component. The selected runtime roots are not a claim to inventory the whole image or all worker memory. Complete Docker metadata/root-layer differences remain separately retained, and any relevant state outside this inventory remains unresolved until the full runtime predicate accounts for it.

All output stays private. File inventories preserve hashes rather than replacing logs, configuration or cache state with wildcards. The future comparison must explicitly handle only prospectively admitted generated values and require all other relevant state to agree. A successful observation does not itself admit any filesystem difference.

They do not inspect local processes or files and do not establish live compatibility. Only syntax and these pure predicates have executed.
