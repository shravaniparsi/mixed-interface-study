# SeatSurfing bounded location request executor

This component executes only the previously source-materialized scalar-edit plan when later called inside an authorized isolated runtime. Preparing/importing/testing it does not authorize application requests. Require the restored fixture identity and exact credential snapshot to be qualified by the enclosing harness. Credentials must remain valid past the shared operation deadline plus one second; reject short-lived credentials before any dispatch. This is the original client's no-refresh branch, not an implementation or qualification of token refresh. The harness must match browser/API authentication and confirm no additional cookie-dependent behavior before scientific use.

Send the main PUT once. Only after its accepted HTTP response, start every retained attribute POST in source/readback order without awaiting an earlier attribute before starting the next. Await completion for evidence collection while explicitly retaining that the original native saved state does not await those attribute responses. Do not add automatic readbacks, repair requests, retries, space/image writes or map writes. Record all request headers/bodies and response headers/bodies, including rejected and partial writes, as private evidence.

One operation has a shared deadline of at most 30 seconds and a 512-KiB response-body observation cap per request. Follow no redirects: an unexpected redirect is unavailable for the current transport mapping. Expiry guards, oversized response, timeout and transport error are instrument/qualification conditions, not application defects. On timeout abort outstanding requests and return a snapshot with pending envelopes retained; do not infer that an aborted request had no server-side effect. The enclosing worker must enforce a process deadline and establish application/network quiescence before any checkpoint/restore. A returned timeout alone never authorizes restart or replay.

The source client uses browser fetch; this executor uses an injected transport (Node fetch by default). Complete native/API method, URL, JSON, meaningful headers, actor, ancillary operation order and outcome equality still require actual ordinary qualification. Browser-added transport headers and cookie semantics must be recorded and assessed prospectively; this component does not certify them. HTTP acceptance does not establish persistence or native compatibility.

Six synthetic tests use injected Response objects, with no network or application execution. They check concurrent ancillary dispatch with retained partial failure, suppression after main rejection, pre-dispatch expiry rejection, bounded stalled observation without resending, response-size failure and redirect rejection. They do not test the application or count as scientific cases.
