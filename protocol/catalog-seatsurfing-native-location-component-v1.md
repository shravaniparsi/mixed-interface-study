# SeatSurfing original native location controls

Prepare ordinary creation and scalar editing using the original visible name, description and announcement controls and button[type=submit][form=form]. Opening an existing editor observes its stable-ID GET and waits for the original form, which appears after the loading path. The edit function never navigates or reloads: the caller must explicitly choose warm state or an independently reopened/restored editor. Creation fills only the three declared text controls; all other defaults remain native and the complete actual request must match the prospectively supplied ordinary payload.

Capture main request/body/headers, response status/headers, created X-Object-ID, complete-payload equality and form completion observations. Preserve mismatches and failed/partial state rather than turning them into a successful control. Main response and saved alert do not establish ancillary completion; the enclosing worker must retain the complete request trace and all persisted outcomes. Helpers have a shared 30-second browser wait/action budget; response decoding and every remaining await require the outer worker deadline.

Read original validity properties without calling checkValidity/reportValidity, changing validity, injecting model state or forcing submit. For invalid controls, click the ordinary button once and record a 500-ms bounded observation with validity/messages and any emitted main requests. This component deliberately does not call that observation a qualified blocked case or claim indefinite request absence. The final runtime recipe must establish relevant network quiescence, actionability and native blocking before scientific interpretation. No programmatic form submission, token injection or application patch is permitted.

Syntax checked locally only. No browser/native application test has occurred. All envelopes and DOM values are private fixture evidence and require sealed retention. Workflow/input selection, native ordinary equality, actor checks, full ancillary trace and checkpoint equivalence remain pending.
