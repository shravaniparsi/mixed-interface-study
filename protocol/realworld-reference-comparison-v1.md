# Retrospective generated-reference comparison v1

This offline engineering analysis addresses the exact-reference comparison gap exposed by the fresh v9 sweep. It does not modify the archived experiment, dispatch applications, create primary samples, or qualify a future campaign. Its rule was developed after observing v9 and must be frozen before prospective use.

Scope is article-update/comment pairs whose branches independently classify as clean under the frozen reducer. Mismatch and unknown-policy branches are not promoted. The original pair result is recomputed, and every gate except literal prefix-state slug and literal consumer path is retained. Native singletons remain outside paired accounting.

Before reference substitution, each branch must have exactly one successful producer exchange, one successful assigned-interface article load before the write, and one successful assigned-interface comment exchange. Requests and responses must be ordered; browser capture IDs must match. The producer response and loaded article must independently project to the recorded prefix state, including the exact branch-local slug. Submitted payloads must match command guards. The consumer must POST to that returned article's comments endpoint. Empty, absent, unresolved or ambiguous references cannot qualify.

Only the proved slug slot and path slot are removed for cross-branch equality. Article content, author, command method and payload stay exact; there is no recursive string substitution. The comparison preserves reset, pre-state, actor, producer-command, producer-status and distinct-branch checks. Existing branch validation retains declared-payload, cleanup, response and comment-parent checks. The archive verifier checks raw hashes and frozen source provenance before replay.

Result: legacy-006 qualifies as a clean pair in this separate retrospective comparison. Legacy-004 and legacy-005 remain incomparable because neither submitted its assigned comment/edit write. The two reference pairs remain clean. Both native controls remain singletons. The original v9 report still contains three incomparable pairs.

The result is an engineering correction, not new evidence of a channel discrepancy or an independent defect. This version intentionally requires clean branches and therefore is not yet a general comparator for mismatch detection. Next work is source-derived corpus readiness reconciliation, followed by the remaining extractor, cost-timing and prospective freeze gates.
