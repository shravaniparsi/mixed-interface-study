# SeatSurfing ordinary native-browser worker

This executable component prepares the native-browser half of the ordinary control. It does not authorize a runtime dispatch or the seven scientific inputs. The complete build, provisioner, joint coordinator, original schema compilation, API comparator and ordinary recipe remain prerequisites.

Run only in the recorded Playwright image (manifest c091b21d9fae78c76e85cd4356431e9b018402f172a214fc7d7a5e9a7e29d8ac, configuration fee853fafa59550d162cef52bca02d907694b44ebf6ef9fb075bcc0c65d8dedb) with Node 24.18.1, Playwright 1.62.1, Chromium 151.0.7922.34 and the recorded executable hash. The executable checks these versions and the binary hash before navigation. The future provisioner must verify the image, use the existing pinned package lock, and start the browser in the network namespace of the network-disabled PostgreSQL container. Application origin is exactly http://127.0.0.1:8080. Both browser and Node timezone must be UTC.

Invocation is `node scripts/extension/seatsurfing_native_browser_worker_v1.mjs TOOLS_DIRECTORY PRIVATE_CONFIGURATION_JSON PRIVATE_NEW_EVIDENCE_DIRECTORY`. Configuration selects native_login (with native email/password/organizationId) or verified_restoration (with exact storagePath, storageSha256 and original nativeCredentials). These files and all resulting evidence are private. The restoration mode verifies original storage bytes and credentials; the outer coordinator must first verify the expected joint manifest hash and database restoration. The mode name does not independently establish joint restoration.

The JSON-lines command interface accepts at most six unique request IDs. Native mode permits login once, ordinary creation at most once, editor opening once, optional capture once, and one scalar edit. Restored mode permits no login or creation and opens the existing stable-ID record. Only the two frozen ordinary edits are allowed: description to `Edit description`, or announcement to `Edit notice`. Different edits/branches require separate prospectively specified restored runs; this component does not authorize those runs. Unknown operations, repeated IDs, failed commands and deadline expiry stop the worker without retries.

Creation uses the frozen complete ordinary payload and original visible controls. Opening retains the native GET readback and waits for browser-network quiet. Opening now reconstructs the original loader inputs from this navigation's captured native GET responses. The complete location readback must equal the editor's observed GET result. Groups, attributes, spaces and feature configuration are derived from those retained responses under the original permission/default rules. Editing rejects caller-supplied materialization inputs and uses this stored reconstruction. The enclosing coordinator must still verify acquisition provenance and full state. The materialized main payload is compared to the original native request. The worker retains every observed ancillary request, but does not yet judge their equality or persistence. It makes no API continuation call.

Capture retains the exact browser storage serialization and network events used by the browser observation component. It leaves the page/context/process alive. The outer coordinator must independently settle application work, verify actor/state and pause browser plus application before the database checkpoint. Resuming this same worker preserves the open editor; edit does not navigate. A restored branch launches a new worker using the verified snapshot. No worker flag substitutes for the required warm-versus-restored ordinary comparison.

Cross-origin HTTP traffic is recorded and blocked; all WebSockets are unsupported and closed. Request failures and unsupported state invalidate quiet observation. Routing is additional protection, not a replacement for the provisioner's network isolation. Service workers are not silently disabled; their presence fails checkpoint qualification. Credentials must remain unchanged with at least two minutes of lifetime. Command size is limited to 64 KiB after line parsing, configuration/storage to 1 MiB after read, and serialized retained evidence to 32 MiB. These are observation limits, not peak-memory guarantees; the enclosing process/container must enforce resource limits. A nine-minute worker deadline supplements the enclosing qualification-job deadline and never permits an experiment retry.
