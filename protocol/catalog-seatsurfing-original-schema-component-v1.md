# SeatSurfing original-schema component

Prepare a Go command importing the original frozen server/router package, then invoke its exported UnmarshalValidateBody with the original CreateLocationRequest type. This uses the application's original JSON decoder, validation tags, GetValidator and exact dependency versions. Do not copy frontend rules or replace the original validator with a reimplementation. It models S (request decoding and declared tag validation), not the complete create/update handler: authorization, timezone lookup, group membership, persistence and procedural handler rules remain outside this schema baseline and must not be represented as checked.

The probe reads one input up to 65,536 bytes, records acceptance/error and the decoded model, and never calls the HTTP handler or persistence methods itself. Invalid/oversized input streams are instrument failures. The frozen module and imported packages may have initialization dependencies; compilation and execution must be assessed only inside the separately registered isolated runtime with network restrictions and a bounded process deadline. No local dependency installation, compilation or schema execution is authorized by this preparation. Any decoded model/error can contain fixture values and belongs in sealed evidence.

The source-import probe is not yet compiled or qualified. Preserve a failure if the original package cannot build or initialize under the recipe; do not silently extract a weaker schema or change dependencies. Ordinary schema checks and all prescheduled altered inputs remain unexecuted. Publish complete workflow/input/runtime registration before use.
