# Oracle-acquisition measurement contract

This contract defines measurement infrastructure before a new cohort exists. It is not a registered scientific execution schedule, automatic-inference method or Q1 contribution. No data collection, model call, service request or installation is initiated here. Synthetic unit-test examples are engineering checks and never enter the paper's sample counts.

Freeze a frame independently of predictions: unique case identifiers, project/workflow/constraint identities, all methods, and intended-state labels with external evidence references. Every method must provide exactly one verdict per case, including explicit not_run entries. A missing or duplicated prediction invalidates the comparison instead of silently reducing its denominator. A provenance reference is required for a resolved label, but code cannot certify its independence or correctness. These must be reviewed before a scientific run.

Canonical verdicts are satisfied, violated, unknown, code_error and not_run. The inspected RBCTest helper labels map satisfied to satisfied, mismatched to violated, unknown to unknown and code error to code_error. This translation is not a full artifact adapter and does not interpret arbitrary generated Python return values. Preserve unsupported output as an integration error; never convert it into success. RBCTest's request-parameter TP-labelled mode remains distinct from an end-to-end automatic mining run and is not qualified by this scorer.

Report coverage together with accuracy. Resolved labels can be satisfied or violated; unresolved labels remain in the retained frame but outside truth-dependent metrics. Precision uses true alerts divided by alerts on resolved labels, and reports alerts on unresolved labels separately. Violation detection uses true alerts divided by all resolved violations, including cases with unknown/error/not_run predictions. False-alert fraction uses false alerts divided by all resolved satisfied cases. Accuracy conditional on a decisive result must always be paired with decisive coverage. An empty denominator is undefined, not 100 percent. Report violations incorrectly declared satisfied separately from violations with no decisive verdict.

Keep results by project and all paired verdicts. Counts of workflows or constraints are cluster identifiers, not proof of statistical independence. Repeated payloads, versions, components or trials of one fault cannot become independent discoveries. The scorer does not produce confidence intervals, macro-average claims, causal diagnoses, cost savings or defect counts. An inferential analysis needs an independently justified unit and design first.

Acquisition precision/recall of rule sets is a separate measurement from verdict accuracy. It needs a prospectively defined constraint inventory and semantic matching procedure, including applicability and legitimate interface-specific requirements. This scorer alone cannot measure rule recovery, certify mined constraints, or claim that a predicate inferred from implementation is intended behavior.

Before scientific use, the method and information-access arms, sample source, held-out exposure policy, independent label evidence, meaningful effect target, repetitions and cost cap must be registered. Log mapping/annotation effort and all model/setup costs separately; no measured human effort reduction follows from assistant execution time. All current application/issue cases remain exposed development material unless an existing protocol establishes otherwise.
