# Fresh-session independent evaluation: design and provenance stage

The fresh-session v3 feasibility passed on two exposed short-link workflows. This plan carries forward the editability/repairability question with fresh browser contexts and verified persistent-state resets. It does not reopen the six selected slots of the closed evaluation or treat feasibility controls as independent defects. This is a design/provenance stage, not a scientific execution registration.

## Sampling decision

Use the existing catalog schedule rather than search for favorable replacements. The terminal record identifies 21 source-unattempted rows, sequences 20–40. These are candidates for provenance review only. Keep their original order and pinned revisions. They are the remainder of an exposed, API-advertising, Docker-filtered catalog sample; they are not a new random sample or representative of all applications. The earlier closures and attrition remain reported alongside this remainder. Do not relabel the entire old study successful.

First reconcile each candidate's reference paths against source collections, application runs and family aliases. Metadata-only references do not disqualify a project automatically; neither does an absent reference establish blindness. Preserve the missing-history count. Any candidate with unresolved history is explicitly unresolved, not certified independent. No source or runtime acquisition is authorized by the reconciliation output alone. The first source schedule must bind the complete review subset and qualifying criteria before sources are read, including disposition rules for unavailable/ineligible projects. No reseeding, reordering or substitution based on defects.

## Measurements and competent comparators

RQ1 measures whether a successful API producer leaves a record supporting an unrelated ordinary native edit in a fresh authenticated browser context. Readback must show the requested edit persisted and all declared unrelated state stayed within its frame. Distinguish producer rejection, normalization, editable acceptance, positively observed blocking, unintended changes and unavailable execution. Timeout alone is not evidence of a validation defect.

RQ2 compares a fixed target-field repair with sham on paired branches restored from the same API-produced persistent state. Both branches start fresh browser sessions under the same actor. The repair is the ordinary control value, frozen before altered-input execution; no error-guided repairs. Include accepted altered states that already edit successfully. Run ordinary repair controls first. A causal interpretation requires restored-state verification, successful sham infrastructure, observed repair persistence and matching continuation actions. Process restarts define initialization, not equality of hidden heaps.

RQ3 compares precommitted predictions with observed continuation behavior. Freeze (H) API response plus exact producer readback, (S) actual original schema validation with dialect/coverage recorded, and (D) original client validation and serialization replay on the loaded record, including defaults and conditional fields. D receives the same actor, record and ordinary edit as the browser. Missing or unsupported rules yield unknown, never a conveniently wrong prediction. Each comparator predicts its proper target: acceptance, schema conformance or native request production; none is silently credited with predicting persisted editability. Report target-specific correctness and incremental resolved observations, not an aggregate accuracy across different targets. Observations used as oracle evidence cannot be fed back into predictions.

## Inputs, clustering and attribution

Retain the original input family: ordinary control, omission and explicit null for at most four scalar text fields in deterministic pointer order, paired with the first independently editable unrelated text field. Original creation defaults and conditional structure must be bound before execution. These are generated stress inputs, not independently authored benchmark cases. Repository lineage and workflow are the clustering units; variants and repeated reset branches do not increase the independent sample size. The study may supply an independent application evaluation, but cannot claim independent natural input sampling from this design.

Separate an observed continuation incompatibility from a confirmed product defect. Defect attribution requires an applicable pre-existing compatibility obligation, exact source provenance, actor/lifecycle agreement and no legitimate interface-specific difference. Schema disagreement alone is not that obligation. Preserve unresolved attribution. No claim of agent improvement without a separately specified agent intervention experiment.

## Execution and analysis before outcome collection

Publish all selected workflows, literal inputs, comparator versions/predictions, state frames, reset checks and branch order before altered-input runs. Qualify the complete pipeline on ordinary inputs first. Diagnose infrastructure errors and allow documented repairs under the user's authorization; do not treat arbitrary preparation deadlines as evidence against the idea. A change to inputs, scoring or scientific logic requires a prospective amendment and separation of previous outcomes. Never discard failures from reliability and cost denominators.

Report the full selection funnel, each workflow's paired outcomes, unique supported obligations and availability for each comparator. With few project clusters, prioritize exact counts and per-project results; no variant-level significance test or global prevalence estimate. Specify any inferential analysis and meaningful effect criterion only after the independent eligible sample is known and before altered outcomes. Null results remain null. Successful feasibility is not Q1 evidence by itself.

Use only existing free standard public runners and sanitized disposable log evidence. No paid model calls, larger runners or new storage services. Record actual runner seconds, failed builds and evidence availability separately; do not equate runner time with human effort or claim the historical $100 balance has been independently reconciled.
