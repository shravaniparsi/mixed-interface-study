# SeatSurfing native editor loader reconstruction

Reconstruct inputs for the already frozen source-materialized scalar edit from the original browser's recorded GET responses. The worker records the last request ID before navigating to the editor, opens it through the existing native component, waits for bounded network evidence completion and reconstructs only requests newer than that boundary. Require the reconstructed location readback to equal the native editor GET captured by the original component. Preserve the full trace and original responses.

The verified source chain is Location page loadData, original Location/Group/Space/SpaceAttribute/SpaceAttributeValue models, RuntimeConfig, and Settings/Permission/Navigation acquired under waves 38/39. Navigation.PATH_API_SETTINGS is /setting/. Permission.Groups is groups and Read is 10. RuntimeConfig.hasPermission uses `(permissions[key] ?? 0) >= level`. Its settings loop starts featureGroups=false and sets it to `value === '1'` in response order for feature_groups. Preserve that behavior, including the default and ordered repeated settings entries.

Require original self, settings, location, spaces, map, attribute-definition/value and timezone responses; require the group list only when the original self permission allows it, and reject a contradictory group request otherwise. Each consumed endpoint must have exactly one successful GET in the fresh navigation window, matching original bearer token, complete body/hash, headers and completion event, with no failed event. Missing, duplicated/ambiguous, corrupt or differently authenticated responses make this reconstruction unavailable. Do not choose a convenient cached/older response or issue replacement GETs. A duplicate-GET qualification rejection is instrumentation scope, not an application incompatibility.

For groups preserve response order. Retain complete raw space records and copy original attribute value fields, including the constructor's empty attributes default where input attributes is absent/falsy. Unchanged spaces are not serialized into an update by this scalar-edit path. Preserve the original location attribute order and values. Retain original map, attribute catalogue and timezone responses even where they do not contribute fields to the main scalar update. Designed-map edits remain outside the existing materializer scope. No file/image/design mutation is added.

The worker stores these reconstructed inputs on open. Its edit operation rejects caller-supplied materialization and invokes the source-derived materializer with the retained loader inputs and one frozen ordinary edit. Do not replace native loading, inject form state or navigate before the warm edit. The native form's actual emitted payload and all ancillary requests still require the later equality checks.

The reconstruction returns acquisitionProvenanceVerified=false and runtimeQualified=false. The outer coordinator must bind the worker launch/trace, original actor, checkpoint and complete persistence comparison. This is not an API-only loader implementation; a competent restored API continuation still requires its independently recorded loading plan from the same restored state. No scientific job is authorized by this component.

Validation: seven synthetic trace tests and worker syntax. Cover complete loading, permission-denied groups, feature setting default/order, stale request boundaries, missing response, altered body/bearer and duplicate ambiguity. No browser, database, application or scientific input ran.
