# Generated RealWorld offline bindings v1

This preparation binds the eighteen exact cases in the frozen generated pool into nine independently reset pair jobs. Both API- and UI-produced reference controls remain, and mutation jobs use the reference with the same producer interface. Pair semantics, case digests and reference identities must equal the retained v3 corpus map. Job order and branch order are immutable within this version. The plan cannot dispatch applications.

Producer payloads retain omission, null, empty strings, whitespace and tag representation exactly. Consumer intent follows the existing generated adapter: after HTTP 201 it uses the returned title, description and tags, replaces the body with the registered edit body, and addresses the returned slug. It does not synthesize an omitted producer field from a default. Resolving intent does not establish that the reference loads or the write runs. Non-201 responses resolve no continuation; empty references remain unresolved. Unknown length-limit policies are copied unchanged.

A pure extractor binds evidence case ID and route to an exact job, then delegates to the source-pinned generated component reducer with mandatory capture and execution-integrity checks. Missing guards cannot produce complete evidence. Shared final UI reads remain separate from assigned-interface actions. Source hashes are recorded for reproducibility, but this pure function is not a file-backed provenance certificate.

Tests use explicit synthetic component fixtures and registered inputs. They do not add observed application outcomes or convert older compact summaries into fresh raw traces. Primary readiness counts are unchanged. Still required: a source-qualified file loader, paired terminal-v2 comparison, bounded per-job runtime supervisor with owned cleanup and branch timing, and appropriate exposed qualification before prospective freeze. Unexpected acceptance must exercise the same evidence rules as accepted controls; a registered rejection alone does not qualify that path.
